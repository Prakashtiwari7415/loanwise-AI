# LoanWise AI

## Vision

LoanWise AI is a visual-first loan decision-support platform designed
to help consumers understand and compare borrowing options.

The system focuses on:

- affordability
- total borrowing cost
- loan comparison
- prepayment scenarios
- interest-rate scenarios
- document analysis
- AI-assisted explanations

## Initial Scope

The first version focuses on car loans.

Home loans will be added after the car-loan workflow is stable.

## Product Philosophy

LoanWise should not overwhelm users with financial terminology or long
paragraphs.

The interface should communicate important decisions through:

- cards
- scores
- charts
- visual comparisons
- sliders
- warnings
- concise AI explanations

## AI Philosophy

AI should explain and orchestrate the system.

Financial calculations must be performed by deterministic Python code.

AI must never invent missing financial information.

## Disclaimer

LoanWise is a financial education and decision-support tool.
It does not guarantee loan approval and does not replace professional
financial advice.
